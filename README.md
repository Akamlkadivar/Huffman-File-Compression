Huffman File Compression

Overview

This project implements Huffman Coding in Python to compress and decompress files using variable-length binary codes.

Features

- Huffman Tree construction
- Character frequency calculation
- Binary file compression
- File decompression
- Original and compressed file size comparison
- Compression ratio calculation

Technologies Used

- Python
- Heap Queue ("heapq")
- Collections ("Counter")
- Struct module
- File Handling

How to Run

Run the Python program:

python huffman_compression.py

Choose an option from the menu:

1. Compress File
2. Decompress File
3. Exit

Purpose

The project demonstrates Huffman Coding, a greedy algorithm commonly studied in Design and Analysis of Algorithms (DAA).
